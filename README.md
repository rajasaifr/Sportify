
Project Overview

Sportify is a real-time sports social platform designed to bring fans together. Built with a focus on low-latency interaction, the application allows users to create dedicated rooms for specific sports, watch live streams, and engage in synchronized communication.

The platform leverages React for a dynamic user interface and Firebase for a robust, scalable backend.

Core Features

Real-Time Messaging: Enables seamless communication within sport-specific rooms using Firebase’s WebSocket-based listeners.

Synchronized Streaming: Provides low-latency, synchronized streaming experiences for users watching live sports together.

Sport-Specific Rooms: Users can create and join various rooms tailored to different sports.

Live Updates: Real-time data synchronization ensures that messages and streams are updated instantly across all connected clients

Tech Stack

Frontend: React 

Backend: Firebase (Firestore, Authentication, and Realtime Database/WebSockets)

Real-time Communication: Firebase WebSocket-based listeners
